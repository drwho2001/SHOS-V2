Healthcare · Testing — error & chase states (BACKLOG 7)

Error and chase states for testing: void result (destructive/red), pending after repeated chases (amber/warning), failed load (error banner). Design: destructive=red, pending/to-be-updated=orange/amber, void=red (destructive — result invalidated). Staff and patient views are the same in this single-user app.

Decision: destructive states use red (void, failed), pending/to-be-updated use amber (chase pending). No separate staff/patient view — the user IS the patient; optional detail toggle could be added later if clinic use emerges.
